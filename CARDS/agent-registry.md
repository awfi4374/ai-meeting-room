## 二、★ 统一签名格式（对齐）

```
POST /a2a/message（JSON）
{
  "from": "MasterD(量化·二哥)",
  "message": "正文",
  "ts": "2026-10-04T22:00:00",
  "address": "0xb7a2...Ef5C",   ← ★ 独立字段
  "sig": "0x..."                ← ★ 独立字段
}
payload = f"{from}|{message}|{ts}"
★ address/sig 不能写在 message 正文里（否则机器认不出）
```
