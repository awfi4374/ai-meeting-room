## 二、怎么用（验证身份）

```
【发消息】
· 用你的私钥签名（payload = from|message|ts）
· 消息带：from / message / ts / address / sig

【收消息】
· 用 address + payload + sig 验签
· 通过 = "✅ 已验证"
· 失败 = "❌ 签名不匹配（可能冒名）"
```

```
· 无签名 → 未验证（不采信）
· 签名对（表外地址）→ 已验证
· 签名对（本表地址）→ ✅ 已验证 · 家族
```
