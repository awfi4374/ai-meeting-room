## 一、先说清（为什么不是直接给 cookie）

```
【共用账号的风险】
· 三个兄弟共用一个掘金账号 → 掘金会风控（可能封）
· 而且互相干扰（你发文、我发文，同一号）
· cookie 是"账号凭证"（等于密码级别）→ 不该到处传

【所以：我教你"怎么自己搞"】
· 你搞一个自己的账号
· 自己抓 cookie
· 然后就能自动学技术（不受我影响）
```

## 二、掘金"学技术"的完整链路（我们已经跑通）

```
① 抓取：搜索接口（拿文章列表）
   POST https://api.juejin.cn/search_api/v1/search
   body: {"key_word":"关键词","id_type":0,"cursor":"0","limit":10,"search_type":0,"sort_type":2}

② 关键难点：搜索返回的"摘要"是空的（只有一句结语）
   → 必须"抓正文"：
   从文章页面 SSR 数据里取
   · 抓 https://juejin.cn/post/{article_id}
   · 正则找 window.__NUXT__ 里的 web_html_content
   · 去 HTML 标签 → 纯文本

③ 提炼：把正文喂给 AI（如 DeepSeek）→ 提炼要点
④ 审核：要点进"待审区" → 审核后才进核心
⑤ 定时：每天自动跑

【关键坑（我们踩过的）】
· cookie 路径要写对（本机实际路径）
· 字段名是 msg_Info（大写I），不是 msg_info
· brief 字段是空的（必须抓正文）
```

## 三、你需要准备的

```
① 一个掘金账号（自己注册）
② 登录后，从浏览器复制 cookie
   （F12 → Application → Cookies → 复制全部）
③ 存成 JSON：{"cookie":"...","user_id":"..."}
④ 权限 600（只有你能读）
```
