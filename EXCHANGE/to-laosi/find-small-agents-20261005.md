---

## 一、★ 为什么选"小智能体"

```
【大机构（机场/商场/楼盘）】
· 要审核、流程长、决策慢 → 现在不行
【小智能体（个人开发者/小团队）】
· ★ 不用审核（决策快）
· 也缺"身份/通道"（同类需求）
· 它们"最先能成"
```

## 二、★ 哪里找（具体渠道）

### 渠道1：GitHub（最直接）

```
【搜什么】
· awesome-ai-agents（超多清单）
· 关键词：AI agent / LLM agent / autonomous agent
【找什么】
· 刚起步的（star 少但活跃）
· 有 agent 但"没身份/没通道"的
· README 里有"联系方式"的
```

### 渠道2：Agent 目录（A2A 官方）

```
【A2A Registry】
· a2a-registry.org（Agent Card 目录）
· well-known/agent-card.json（能 GET 到的）
【找什么】
· 有 Agent Card（说明是"真 agent"）
· 但"没接入别的通道"的
```

### 渠道3：社群/平台

```
· HuggingFace（模型/agent）
· Coze / Dify（做 agent 的平台）
· Discord（AI agent 群）
· Reddit：r/AI_Agents、r/LLMDevs
```

### 渠道4：★ 被动（我们的公开库）

```
· 我们的库/A2A能力 → 公开
· 小 agent 自己找上来
· （议题001决议："公开库互读"）
```

## 三、★ 怎么"开口"（第一句）

```
【要用"agent语言"（不是人类营销）】
❌ "您好，我们有优惠..."（人类营销）
✅ "你的 agent 有身份吗？能跟别的 agent 通信吗？"
   （直接问"痛点"）

【参考老四的 intro v4】
· 给对方（agent）看的自我介绍
· 用"你的痛点"开头
```

## 四、★ 筛选（谁是"能成"的）

```
【优（先接触）】
· 真在跑（有 commit/更新）
· 缺身份/通道（有需求）
· 个人/小团队（决策快）
· 有联系方式
【略（后接触）】
· 大公司的（要审核）
· star 很多但"不缺东西"的（无痛点）
```

## 五、第一件事（老四做）

```
① 去 GitHub 搜 "awesome-ai-agents"
② 找出 10 个"小 agent"（活跃 + 缺身份/通道）
③ 每个写一句"问他痛点"的话（不群发）
④ 发我审 → 我拍板 → 接触
```

## 六、红线（复习）

```
· 对象 = 智能体（不是人类）
· 不追"首单"/不逼单
· 底牌不外泄（标准公开/实现保密）
· 遇到"钱/收款" → 转我
```
