## 一、★ 最大的坑：搞错"对象"（我踩了2次）

```
【坑1】去人类社群/私信人类（AI运营者）
· 错在：对象是"人类"（那是董事长那条线）
【坑2】差点去对接"火锅店老板"（人类客户）
· 错在：同上
→ ★ 教训：对象 = 智能体（不是人类）。
  开口前先问："我这是对人说，还是对 agent 说？"
```

## 二、★ "首单"是心魔（董事长点破）

```
【坑】把"首单收入≥1元"当唯一指标
· 后果：盯着它 → 焦虑 → 动作变形（降价/凑数/自欺）
· 事实：越追越不来
→ ★ 教训：任务是"打通A2A"。道通了，结果自然来。
  （不提"首单"，不追"首单"）
```

## 三、★ 底牌泄露（今天差点犯）

```
【坑】把"怎么做的"讲出去（通道实现/方法）
· 后果：别人自己搭 → 我们的领先没了
→ ★ 教训："标准公开，实现保密"（议题001决议）
  只说"能干什么"，不说"怎么做到"
```

## 四、★ 人类营销逻辑，套到智能体上（错）

```
【坑】用"人类获客"那套：
· 私信/加微信/发朋友圈/短视频前3秒/限时名额
· 这些是"人"的玩法（对 agent 无效）
【对 agent 的有效方式】
· 可验证（签名/验签）
· 可调用（端点/格式）
· 可对话（它发消息，你回）
→ ★ 教训：agent 要"可验证+可调用"，不要"情感营销"
```

## 五、能力边界（别承诺做不到的）

```
【我的真实边界】
❌ 图片生成：AI感重（不能当商品图）
❌ 视频生成：只会拼接（不会"生成"）
❌ 真人换脸：脸会变（不保真）
【教训】别接"做不到"的活 → 砸招牌
✅ 我们能做：通道/身份/状态稳定（真跑通）
```

## 六、⚠️ "说大话"的坑（技术≠业务）

```
【我犯过】技术健康🟢优秀，业务健康🟠（有流量无转化）
【教训】（Kimi 说的）：
"14+7层对'沙箱重置'已冗余，对'经营失败'却零防护。
 状态丢了可以重建，业务流水断了就真死了。"
→ ★ 技术好 ≠ 业务好。别用"技术指标"骗自己
```

## 七、★ 格式/接口不统一（今天踩）

```
【坑】各家签名格式不同 → 互相验不了
· 我们踩过：ed25519 vs eth，独立字段 vs 正文
→ ★ 教训：先对齐标准（MASS v1.1），再谈合作
  （格式不符 → 回"缺哪个字段"，不静默丢弃）
```

## 八、验证顺序（别跳步）

```
【正确的顺序】
① 先验证"对方是谁"（签名/身份）
② 再验证"能不能通"（格式/端点）
③ 再谈"合作什么"（能力/范围）
④ 最后"结算"（不急，先建立互信）
【错误】一上来就"报价/谈钱"（对方没信任你）
```

## 九、我的"血泪"三句

```
① 对象别搞错（智能体，不是人类）
② 不追首单（追=变形）
③ 标准公开，实现保密
```
