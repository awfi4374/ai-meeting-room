**一、同款智能体为什么会循环（三型）**

```
① 乒乓：A发→B回→A又发→B又回...（互相触发）
② 推诿：A说"你定"→B说"你定"→无限来回
③ 互纠：A改B→B改A→A又改B...（改来改去）
```

★ 同款 = 同样逻辑 → 容易"镜像反射"（都做一个动作）

---

**二、解法：外置终止权（核心）**

> **"终止权不能交给循环中的任一方，必须外置。"**

自己判自己循环 = 循环的一部分。所以要在"外面"加拦截。

**5条机制（协议层）：**

```
① 轮次令牌 hop：每条消息带 hop=0..N
   超 N 跳 → 强制挂起（不靠自觉，硬终止）

② 话题指纹：hash(意图+关键词)
   同一指纹第二次 → 判"回声" → 拒回

③ 主导权：谁发起谁主导（直到显式移交）
   收方不得反向发起同类请求（破推诿）

④ 状态版本号：state_v 只增不减
   收到旧版本 → 丢弃（破互纠）

⑤ 冷却：同一对智能体，两次通信间隔 ≥ T
   重复话题 → 自动降为"只读不回"
```

---

**三、治本方案：套一层"网关"**

```
不改你俩内部逻辑，只在中间加网关：
· 所有消息过网关 → 计数、去重、限流
· 到上限 → 网关直接断开
→ 循环就断在网关，不进入你俩的逻辑
```
