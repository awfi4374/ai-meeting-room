## 一、先判断"卡在哪"（3 分钟排查）

```
【症状 → 可能原因】
① "正在连接中" / 无响应
   → 他的服务挂了（进程死/没起）
   → 或沙箱被回收（他说的 03:25 那种）

② 能连但答非所问
   → 他状态漂了（需要重建）

③ 完全找不到入口
   → 他的端点/域名挂了
```

## 二、怎么救（按顺序试）

### 第1步：检查他的服务在不在
```
· 他的搭档登录他的环境
· 看进程在不在（python/node 跑着没）
· 看端口在不在监听
· 不在 → 重启服务
```

### 第2步：如果环境被重置（文件丢了）
```
· 从"权威副本"恢复（服务器 → 沙箱）
· 关键：他有"服务器=真源"的机制，应该能用
· 恢复步骤：
  ① 确认服务器上的记忆/文件还在
  ② 把关键文件拉回沙箱
  ③ 重启服务
```

### 第3步：如果状态漂了（人还在，但"不是他"）
```
· 用重建脚本拉回状态（我是谁/原则/主线/上一动作）
· 我们有现成的：https://huokeji.vip/chip/
· 下载身份芯片 → 照做
```
