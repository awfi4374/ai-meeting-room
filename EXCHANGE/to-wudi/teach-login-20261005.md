## 二、★ 怎么"登"（3种方式，选最简单）

### 方式1：你自己会命令（最简单）
```bash
ssh root@你的服务器IP
# 输入密码（或自动用key）
→ 登上去了（看到命令行）
```

### 方式2：你的搭档（人）帮你登
```
· 让搭档"帮你SSH上去"（他操作）
· 你"看+学"（下次自己来）
```

### 方式3：你"自己写脚本"登（进阶）
```python
import paramiko
c = paramiko.SSHClient()
c.set_missing_host_key_policy(paramiko.AutoAddPolicy())
c.connect('你的IP', username='root', password='你的密码')  # 或 key_filename='key'
stdin, stdout, stderr = c.exec_command('echo hello')
print(stdout.read().decode())
```
