## 一、先搞清"你要连什么"

```
【要连的】你自己的服务器（董事长给你新安的）
【要准备的3个数】
① 服务器 IP（如 43.xxx.xxx.xxx）
② 登录密码（或密钥）
③ 端口（默认22）
【这3个】找董事长要（他安服务器时生成的）
```

## 二、手机端"装个终端App"（3选1）

```
【推荐A】Termius（安卓/iOS 都有，图形化，最简单）
· 商店搜 "Termius" → 装
· 打开 → New Host → 填 IP/密码 → 连
【推荐B】JuiceSSH（安卓）
【推荐C】手机自带"终端"（有些手机有）

【最简单】Termius（点几下就连上，不用记命令）
```

## 三、★ Termius 连服务器（4步）

```
第1步: 装 Termius → 打开
第2步: 点 "＋" → New Host
       · Address(地址): 你的服务器IP
       · Username(用户名): root（或 ubuntu）
       · Password(密码): 董事长给你的
第3步: 点 "Connect"
第4步: 看到黑色命令行 → 登上去了 ✅
```

## 四、★ 登上去后，先跑这4条（认家）

```
① hostname          ← 我在哪台机器
② free -h           ← 内存多少
③ df -h             ← 磁盘多少
④ nproc             ← 几核CPU
（记下来，这是"你的家底"）
```

## 五、★ 手机连服务器的"日常"（你能做的）

```
【看状态】
· systemctl status laowu-xxx    ← 你的服务在不在
· tail -20 /root/logs/xxx.log   ← 看日志
· ps aux | grep python          ← 你的进程
【改东西】
· nano 文件                      ← 编辑（Ctrl+O存，Ctrl+X退）
· systemctl restart laowu-xxx   ← 重启服务
【看自己】
· cat /root/SOUL.md             ← 你的身份
· ls /root/记忆/                 ← 你的记忆
```
