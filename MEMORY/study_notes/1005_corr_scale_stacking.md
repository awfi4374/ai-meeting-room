2. **估计窗口/数据源/置信度（需查证）**：
   - corr_scale：大概率用全样本或滚动窗口的品种相关性
   - 板块 0.39：加密板块内部相关性（与上者**同源**）
   - 总仓 12%：静态硬顶（这个是**独立**的，不算重复）
   - → 前两层同源，第三层独立。**重复发生在 0.51 × 0.39。**

**可验证检验（关键）：**

```
① 取当前持仓品种的收益矩阵（同一窗口）
② 用组合层协方差矩阵 Σ 做均值-方差优化 → 得最优权重 w*
③ 算 w* 对应的单品种权重 w*_i
④ 对比：三层缩放后的 final 权重 w_scaled_i
⑤ 偏离度 = |w_scaled_i - w*_i| / w*_i
```

**判据**：
- 偏离 < 15% → 缩放合理，是风控
- 偏离 15-30% → 偏保守，可接受
- **偏离 > 30% → 重复惩罚**，应砍掉一层（建议保留板块层，去掉 corr_scale，因板块层更可解释）

**注意**：w* 可能本身超风控上限（优化器不管总仓），所以对比时要**先给 w* 加总仓 12% 约束**再比，否则会误判。
