## DeepSeek

**DeepSeek 回答：**

**年化侵蚀**：费率 f（每8h）× 3 × 365 = f×1095。取中值 0.05% → **54.75%/年**；0.1% → 109.5%/年。$150 账户按 5x 杠杆、名义 $750，费率按名义收：0.05% × 750 = $0.375/8h = **$1.125/天 = 年 $410**，等于本金的 2.7 倍——**小账户高杠杆下费率是本金级杀手，不是"成本项"**。

**进信号的可操作口径**：

1. **净持仓成本（每8h）** = |funding_rate| × 名义仓位 ÷ 本金。设阈值 **0.15%/天**（本金口径）。
2. **强制不开仓线**：`预期持仓期收益 < 费率成本 × 2` 时不开。即预期持 3 天、费率 0.05%/8h（0.15%/天）→ 成本 0.45%，则要求信号预期收益 **> 0.9%** 才开。
3. **换边规则**：费率 > 0.1%/8h 且方向与费率同向（做多正费率）→ 直接否决；反向（做空收正费率）→ 可放宽到 1.5 倍阈值。
4. **代码落地**：在 risk_gateway 里加 `funding_gate(symbol, side, horizon)`，返回 `block / allow / allow_with_reduced_size`；reduced_size = 本金 × (1 − funding_cost/expected_return)。

**一句话**：把费率当**负 alpha 直接扣进预期收益**，扣完 < 0 就不开——别当手续费事后算。
