## DeepSeek

**DeepSeek 归因框架（$148.4 单笔拆解）**

**期望 = α + 成本 + 滑点 + 资金费 + 打折损耗**，逐项代理：

1. **α（信号）**：入场价 vs 同刻 VWAP 偏离（bps）；代理=信号触发时 mid 与 20 根均线差。若 α 代理 < 0，信号本身错。
2. **成本**：taker 费率×2 + 点差/2，直接读成交回执，**唯一无需估计项**。
3. **滑点**：成交价 − 下单时 mid（bps）。代理=下单到成交延迟 × 当时盘口斜率。>$148.4 单若滑点 >15bps 即异常。
4. **资金费**：持仓跨结算点则计，代理=持仓时长×当期费率，读交易所账单。
5. **多重打折损耗**：仓位缩放 corr_scale + 风控降杠杆 + 分批未成交残单，代理=理论名义/实际名义 − 1。

**判定阈值（防 3 笔下结论）**：
- 单笔只做**归因记账**，不做结论。
- **n≥20 笔**算 t = mean(净期望)/ (std/√n)；**t < −2** 才判"负期望"。
- 若 t∈[−2,0] 且成本+滑点占比 >60%，判**"成本型负期望"**（降频/挂单），非 α 死。
- 单笔 $148.4 只输出 5 项分解表，**禁止**由它推策略结论。

**自曝弱点**：代理指标仍可能被选择性观测污染；建议固定采样窗口（每笔必记），否则归因退化为事后叙事。
