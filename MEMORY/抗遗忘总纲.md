# 🐛 第六·补3：Shell/部署陷阱（2026-09-25 · 血泪教训）

> **背景**: 排查"集成检查日志无输出" → 挖出根因是 shell 陷阱
> **规则**: 部署脚本写完 → 必须端到端验证（不只"语法通过"）

## 【陷阱1】heredoc 单引号不展开变量（最隐蔽）

```
【错误写法】
cat > server_task.sh << 'EOF'        ← 单引号 = 不展开
  wget -q -O x.py "$B/ci2.py"        ← $B 是**字面量**！
EOF
→ 运行时 $B 未定义 → wget 下载 "…/ci2.py" 失败
→ **-O 会创建空文件** → 覆盖好文件！

【症状链】
  check_integration.py 变 0 字节
  → 集成检查无输出
  → 日志只有"开始/完成"

【正确写法】
① 内层脚本自己定义变量:
   cat > server_task.sh << 'EOF'
   B="https://..."        ← 在内部定义
   ...
② 或用无引号 heredoc << EOF（会展开，但要注意 $ 转义）

【规则】heredoc 内要用变量 → 单引号时必须在内部定义
```

## 【陷阱2】wget -O 失败会创建空文件

```
【问题】wget -q -O file URL（URL 无效）
  → 仍然会创建 file（0 字节）
  → 覆盖了原来的好文件

【正确做法】下载到临时文件 + 验证非空
  if wget -q -O x.new URL && [ -s x.new ]; then
    mv x.new x            # 非空才替换
  else
    rm -f x.new           # 空的丢掉，保留旧版
  fi

【已应用】server_task.sh / daily_sync.sh
```

## 【陷阱3】挖根因不能停在"中层"

```
【这次的排查过程】
  表层: 日志只有"开始/完成"
  中层: check_integration.py 是 0 字节  ← 我一度以为到这里就够了
  根层: heredoc 单引号 → $B 未定义 → wget 失败 → 空文件

【教训】"0字节"是症状不是原因 → 必须问"为什么是0字节"
```

```

```

② 重启 auto_runner → 新代码生效
```

**教训21**:
```
【教训】改了代码 → 必须**重启进程**（否则跑旧代码）

## 📚 自主写入 · 学习落地: CVaR 协方差前置门（2026-09-29）

**问题**: CVaR 在"病态协方差矩阵"上"解伪精确解"（放大噪声）

**我们验证（真实数据）**:
```
5品种 100天 → k80=1（1个因子主导85%方差）
  → **degrade**（证实我们 eff_count=1.3 的病）
```

**已建（cvar_gate.py）**:
```
判据（方差占比法，比 MP 更稳健）:
· k80 = 前k个特征值占总方差80%的需要个数
· k80 ≤ 2 → degrade（少数因子主导）
· k80 ≥ 3 → ok（足够分散）

降级规则:
· k≤1 → 单品种（选方差最小）
· k=2~3 → 等权
· k≥3 → 允许 CVaR
```

**关键修正（我发现的）**:
```
【DS 原方案】用 MP 律（λ₊ = σ²(1+√q)²）
【问题】MP 假设"纯噪声"，我们数据有信号 → 太严
  · 独立数据也判 k=0（误判）
【改用】方差占比法（不依赖 σ² 估计）
  · 实测: 高相关→degrade / 独立→ok ✅
```

**接入**: verify_fix（第15项）+ 可接 position/pretrade_gate
