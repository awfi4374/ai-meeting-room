# 双时钟实验（定性"冻结 vs 被杀"）

## 问题
沙箱进程"不稳定"：是"冻结"（SIGSTOP）还是"被杀/回收"？

## 方法
每分钟记录:
- wall（墙上时钟，冻结期间**继续走**）
- MONOTONIC（单调时钟，冻结期间**暂停**）
- boot（= wall - mono，重启会变）

## 判定
- 仅 wall 跳 → **冻结**
- boot 变 / mono 归零 → **被杀/回收**

## 实测结果（2026-10-01 ~ 10-03）
```
2026-10-01 07:26  KILL/REBOOT（boot 变）
2026-10-03 03:25  KILL/REBOOT（boot 变）
→ 都是"被杀/回收"（不是冻结）
→ 间隔 ~44 小时/次
```

## 结论
- 沙箱"回收"是常态（~2天一次）
- **任何"常驻"都不可靠** → 只能"可重入 + 外部守护"
- 恢复必须"从外向内"（沙箱内一切会死）
