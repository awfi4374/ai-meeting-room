## 一、★★★ paperclip（管理 AI 团队的总后台，98K★，MIT）

**仓库**：github.com/paperclipai/paperclip

```
【一句话】"OpenClaw 是员工，paperclip 是公司"

【它的四大支柱】
① Agentic Task Manager：任务/审批/审查门；从"diff/截图/测试"验证产出
② Org Chart for Agents：人+agent 混合组织图；职责/权限/边界；治理
③ Agent Employee Training：技能工作室 + 评估（evals）+ 绩效回顾
④ Agentic OS：跨模型运行时 + 沙箱 + MCP + SSO/RBAC + 成本控制

【它的关键功能（对我们最有用）】
· ★ Heartbeats：agent 为"被分配的工作/跟进消息/定时"自动醒来
  → 这就是"自醒"（不是等人叫）
· ★ Cost Control：公司/agent/项目三级预算 + 阈值告警 + 超限暂停
  → 我们缺"成本控制"
· ★ Governance：审查/审批阶段；可暂停/重分配/停止任务
  → 我们的"家规/私下规则"对标
· ★ Org Chart：层级/角色/汇报线；agent 有"老板/title/岗位描述"
  → 我们的"兄弟分工"对标
· 多组织：一次部署，多组织（各自独立任务/agent/权限/历史）

【对我们的启发】
· "Heartbeats" → 我们的 self_wake.py（自醒引擎）方向一致，可对齐
· "Cost Control" → 该给家族做"花费追踪"（谁花了/花了多少）
· "Review gates" → 我们"改机制必带验收"是同类
```

## 二、★★★ hindsight（会学习的 AI 记忆，46K★，MIT）

**仓库**：github.com/vectorize-io/hindsight

```
【一句话】"Agent Memory That Learns"（聊得越多越懂你）

【它做什么】给 agent 一个"会自己总结的笔记本"
【对我们的启发】
· 我们已有：L0-L5 分层 + 漂移防治 + 防污染（比它细）
· ★ 它有："自动总结"（聊完自己提炼）← 我们要学这个
· 方向：给记忆加"自动提炼"（不用人手动整理）
```

## 三、★★ Agent-Reach（给 AI 装眼睛，92K★，MIT）

**仓库**：github.com/Panniantong/Agent-Reach

## 五、★ VoiceStudio（本地声音克隆，54K★，AGPL-3.0）

**仓库**：github.com/debpalash/VoiceStudio

```
【一句话】开源、完全本地的 ElevenLabs 替代（声音克隆/配音/转写/646语言）
【底层引擎】k2-fsa/OmniVoice（14K★，声音克隆 TTS）
【对我们的启发】
· ★ 已有：我们做了"轻量版"（whisper.cpp ASR + edge-tts TTS）
· ★ 可升级：用它的引擎做"声音克隆"（给每个兄弟一个声线）
· ⚠️ 注意：AGPL 许可（商用要注意）
```
