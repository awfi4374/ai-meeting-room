# 架构审计（从"验收"到"审计"）

## 问题
```
91轮评审 → 16个真问题 → **全是"已有的坏了"**
零个"该有的没有"（缺失层）
```

## 根因（Kimi 定性）
```
"不是某次答错，是**观测体系设计缺陷 + 元盲区**"
· 评审只做"验收"（已有的坏了）
· 不做"架构审计"（该有的没有）
· 且"看不到缺失层"这件事本身没被看到
```

## 对策（5条）
```
① **架构对照评审**（评审模板加"缺哪层？"）★
② 负空间日志转正（"待建"定截止期）
③ 修复单加"观测归属"（哪层本该更早发现）
④ 慢性问题改规则（第2次复发即问"观测层缺失"）
⑤ 季度外部对照（防内循环自洽）
```

## 效果（实证）
```
【之前】91轮 → 零个"缺失层"
【加了"架构审计"】B组主动回答"缺 L1/L4"
→ **评审能发现"缺失层"了**
```
