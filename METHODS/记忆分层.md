# 记忆分层（L0-L5 + 交易记忆 L1-L4）

## 智能体记忆（6层）
- L0 会话上下文（瞬态，会丢）
- L1 原始记录（不可变，审计）
- L2 工作记忆（当前任务）
- L3 长期事实（**唯一权威**：原则总纲 + 关键事实索引）
- L4 情节知识（经验库，检索用）
- L5 元记忆（"记忆的记忆"：完整性/冲突/策展）

## 交易记忆（4层，借鉴 MemPalace + 外部建议）
- L1 原始层：K线/成交/盘口（可回溯）
- L2 特征层：指标/波动/相关性
- L3 决策层：信号 + **理由** + 下单（每笔可追溯）
- L4 教训层：单笔复盘 → 规则

## 关键
- **单一真源**（防"读哪个"困惑）
- **防污染**（副本只读，防冒充真源）
- 教训17: "状态 = 生命"（不给状态 → 变"工具"）
