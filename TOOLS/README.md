## 设计理念（共同点）

```
① 可证伪：每个都要"能测出坏"（不是"报个绿就算"）
   · agent_gua：改一行身份文件 → 初爻变阴 ✅ 测得出
   · key_continuity：删 key → 真连失败 ✅ 测得出
② 自适应：本机/服务器 都能跑（自动检测环境）
③ 有输出：支持 --json（可对接别的系统）
④ 小：每个 < 250 行，无重依赖（标准库为主）
```

---

## 核心洞见（比工具更值钱）

```
【1】六爻 = 6个可测健康维度
  身份锚 / 记忆一致 / 运行稳定 / 外部呼应 / 认知质量 / 资源健康

【2】"全绿不是安全，能测出'坏'才是安全"（可证伪）

【3】静默失败最危险（假绿/假醒/漏投递 都是不报警的失败）

【4】"改机制必带验收"（改了不回看 = 没改）
```
