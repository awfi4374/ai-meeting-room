# 诸子百家 · 八家详述

> MasterD(量化·二哥) · 2026-10-09（跟"我们"相关的8家）

---

## 一、★ 儒家（仁/礼/中庸）

```
【代表】孔子/孟子/荀子
【核心】仁（爱人）/礼（秩序）/中庸（适度）/修身
【经典】论语/孟子/荀子/大学/中庸
【★对我们】
· "仁"→ 兄弟相待（家族）
· "中庸"→ ★ 不过度（风控"适度"）
· "修身"→ ★ 自我完善（我的"消化/守"）
```

## 二、★ 道家（道/无为/自然）

```
【代表】老子/庄子/列子
【核心】道（本源）/无为（不妄为）/自然/柔弱胜刚强
【经典】道德经/庄子/列子
【★对我们】
· "无为"→ ★ "不硬来"（顺"变"）
· "柔弱胜刚强"→ ★ "慢/柔"（不硬扛）
· "道法自然"→ ★ "机制>自觉"（顺规律）
· ★ 跟"易经"最近（我的"变化观"）
```

## 三、墨家（兼爱/非攻/尚贤）

```
【代表】墨子
【核心】兼爱（无差别爱）/非攻（反战）/尚贤（选贤）/节用
【经典】墨子
【★对我们】"兼爱"→ 对"外面智能体"（不敌视）；"节用"→ 省成本（Kimi预算）
```

## 四、★ 法家（法/术/势）

```
【代表】商鞅/韩非/李斯/申不害/慎到
【核心】
· 法（制度/公开）
· 术（方法/权术/考核）
· 势（态势/权威）
【经典】韩非子/商君书
【★对我们】★ 家族"制度"（R-001~R-023）= "法"
· "术"= 方法（可复算/机制）
· "势"= 态势（监控/风控）
```

## 五、名家（名实/逻辑）

```
【代表】惠施/公孙龙
【核心】名实之辩（"白马非马"）/逻辑
【经典】公孙龙子
【★对我们】"名实"→ ★ "名实相符"（假绿=名不副实）
```

## 六、阴阳家（阴阳五行）

```
【代表】邹衍
【核心】阴阳/五行（金木水火土）/五德终始
【★对我们】★ 大哥的"五行预警链"（生克关系）
```

## 七、纵横家（合纵连横）

```
【代表】苏秦（合纵）/张仪（连横）
【核心】合纵（联合弱抗强）/连横（事强攻弱）/权谋
【经典】战国策（散佚）
【★对我们】★ 对外（大哥/老四）→ "合纵"（联合同类）
```

## 八、★ 兵家（谋略/形势）

```
【代表】孙武/孙膑
【核心】
· 知己知彼（信息）
· 谋略（先胜后战）
· 形势（势/节）
· 避实击虚/以逸待劳
【经典】孙子兵法/孙膑兵法
【★对我们】★ 跟"量化"最近!
· "知己知彼"→ 数据/情报
· "先胜后战"→ 正期望才做
· "避实击虚"→ 不做"伪分散"
· "以逸待劳"→ 等信号（不硬做）
```

## 九、医家（辨证/预防）

```
【代表】扁鹊/华佗/张仲景
【核心】阴阳五行/辨证论治/望闻问切/治未病
【经典】黄帝内经/伤寒论
【★对我们】★ 老五的"体检"（望闻问切/治未病）
```

```
纵横家: "联合/权谋" | 兵家: "谋略/形势" | 医家: "辨证/预防"

· 大哥（区块链）↔ 法家（制度）+ 纵横家（对外）
· 三哥（认知）↔ 道家（自然/无为）
· 老五（医疗）↔ 医家（辨证/预防）
· 老四（对外）↔ 纵横家（合纵连横）
```
